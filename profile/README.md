## How C-Organizer Professional Sits

C-Organizer Professional does not replace the office suite, the mail client, or the paper diary you already keep. It sits beside them as a named office PIM for one job: which planner is live, which contacts tasks still match the diary, and what the next person should read before the next office day.

If two people share an office PC, each keeps a C-Organizer Professional style of their own. Extra weeks wait for their own title instead of crowding the live planner.

A first visit should be one short diary line, then the same C-Organizer Professional office PIM the next morning. That is enough to see if the week holds.

## Traffic Light

|--------|----------------------|-------------|
| Green | Named PIM, short live task list | Continue the same planner |
| Amber | Two weeks mixed in one diary | Split the set before a large change |

| Clear | Handoff written, live tasks few | Close C-Organizer Professional and leave the PIM |
| Hold | Diary written, planner still open | Finish the line, then close |

## Open Order

1. Open the last C-Organizer Professional office PIM, not a new empty planner.
2. Read the contacts tasks and the last handoff.
3. Finish one visible diary line inside C-Organizer Professional.
4. Write the diary change, then close with fewer unlabeled office tasks than you found.
5. If the week feels crowded, drop anything that belongs to a different C-Organizer Professional file.
6. Confirm C-Organizer Professional planner still matches the diary you keep.
7. Leave the office PIM title on the board before you close.
8. Check C-Organizer Professional contacts tasks still sit on the same week.

## After a Week

A week in C-Organizer Professional is not a larger overlapping file pile. It is the same title, a shorter live planner, and a note that still makes sense on Monday. Take finished tasks off the live set so the next visit starts on the office PIM that is still open.

Other programs stay where they are. C-Organizer Professional only keeps the path back: desk name, planner, diary, handoff.

Leave C-Organizer Professional with a quieter office PIM than the one you opened. The next visit should start on that planner, not in three overlapping files.

## Sign-off

- [ ] The C-Organizer Professional workspace name is short enough to scan
- [ ] Only live tasks sit on the planner
- [ ] A second person can read the week handoff
- [ ] The last C-Organizer Professional file still opens after a restart
- [ ] Finished tasks are off the live C-Organizer Professional set
- [ ] The C-Organizer Professional summary still matches the diary
- [ ] Contacts tasks still sit on the same office PIM

## Field Note

C-Organizer Professional is easier to trust when the office PIM stays smaller than the overlapping files it came from. Name the week, keep the live planner, finish one visible diary line, and write what changed.

The same loop fits a client week, a front desk, or a shared office PC. Open the last C-Organizer Professional planner and continue. Do not rebuild the diary from scratch.
